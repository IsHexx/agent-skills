# Excel 用例工作簿约定

## 目标
保证 `.xlsx` 中的测试用例可被自动校验、可持续回归、可批量追加。

## 必备列（表头必须完全匹配）
- 编号
- 目录
- 优先级（P0/P1/P2/P3）
- 标题
- 前置条件
- 步骤描述
- 预期结果
- 负责人
- 用例类型

## 表头与数据行
- 默认每个 sheet 的第 1 行为表头。
- 数据从第 2 行开始；允许存在空行（脚本会跳过全空行）。

## 编号建议
- 推荐格式：`TC-001`、`TC-002` …（脚本按 `TC-(数字)` 识别）
- 若需“全工作簿唯一且递增”：追加时使用 `--id-mode auto` 由脚本基于全工作簿最大值自动分配。

## 单元格换行
- Excel 中允许单元格内换行；导出到 Markdown 时会转为 `<br>`。
